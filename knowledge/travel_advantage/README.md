# Travel Advantage Knowledge Base staging area

Эта папка предназначена для подготовки базы знаний Travel Advantage / MWR Life к последующему воспроизводимому импорту.

- `sources/` — официальные исходные материалы, документы, тексты и таблицы. Исходники сохраняются без подмены их смысла и с указанием происхождения.
- `imports/` — нормализованные структурированные данные, подготовленные для идемпотентной загрузки через будущий repository/service слой.

Это не runtime-база знаний и не источник ответов приложения напрямую. Runtime-данные позднее должны храниться в SQLite и читаться через выделенный repository/service слой.

Правила использования:

1. Не редактировать официальные исходники так, чтобы менялся их смысл; нормализацию выполнять в `imports/`.
2. Для каждого набора импортируемых данных сохранять стабильные ключи и ссылку на источник.
3. Не загружать данные напрямую в production DB и не подключать эту папку к Conversation Core без отдельного этапа реализации и проверки.
4. Факты `verified_official` можно автоматически использовать в обычных информационных ответах после Safety Layer. Ручное одобрение требуется для прогнозов или обещаний дохода, персональных расчётов потенциального заработка, конфликтующих или неоднозначных сведений, unsupported claims, непроверенных статусов и явно отмеченных источником случаев дополнительной проверки.
5. Переданные владельцем официальные данные хранятся как `verified_official`. Отсутствующие PDF, страница, версия или effective date не выдумываются и не понижают статус.
