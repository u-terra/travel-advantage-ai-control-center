# Normalized import dataset v1

Импортируемый JSON имеет пять корневых полей:

```text
dataset_version: 1
sources: KnowledgeSource[]
items: KnowledgeItem[]
facts: KnowledgeFact[]
examples: KnowledgeExample[]
```

Все сущности имеют уникальный `stable_key`. `source_reference` определяет официальный документ, а обязательный `source_ref` — конкретный заголовок, блок или раздел внутри него.

Переданные владельцем официальные данные сохраняются как `verified_official`, даже если исходный PDF, страница, версия или effective date не приложены. Отсутствующие реквизиты не выдумываются; provenance указывает доступный локальный источник и конкретный смысловой блок через `source_ref`.

Числа и условия хранятся только в `facts`. FAQ и объяснения ссылаются на items/facts, а каждый practical example обязан перечислять `fact_refs`. Повторный импорт выполняет UPSERT по `stable_key` в одной транзакции.

До открытия транзакции importer проверяет версию формата, допустимые поля, ссылки, типы значений, уникальность ключей и отсутствие двух фактов с одинаковой канонической предметной идентичностью.
